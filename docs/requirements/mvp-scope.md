# DotaFrame — границы продукта

**Версия:** 1.0  
**Дата:** 12.11.2026  
**Предыдущая версия** (план MVP v0.6): [archive/mvp-scope-v0.6.md](../archive/mvp-scope-v0.6.md)

Документ описывает, что входит в продукт сейчас и что осталось за его границами. Подробное описание функций — в [README](../../README.md).

## 1. Цель

Редактор вводит данные серии Dota 2 один раз и получает из них разные публикации: анонс, афишу игрового дня, WIN / LOSE, итог серии и драфт карты. Сохранённые публикации не меняются при правке справочников.

## 2. Что входит

| Область | Состав |
|---|---|
| Справочник команд | Название, короткое название, регион, заметки, логотип (PNG/JPEG/WebP/GIF/SVG) |
| Матчи | Две разные команды, турнир, стадия, дата, время, часовой пояс, BO1/BO2/BO3/BO5, статус, счёт с проверкой формата |
| Шаблоны | Match Announcement, Matchday (1–6 матчей), WIN, LOSE, Series Result, Dota Draft |
| Редактор | Данные, оформление (темы, цвета, фон, фото игрока, шрифты, видимость элементов), живой предпросмотр, undo/redo, проверка макета |
| Драфты | Радиант/Дайр, по 5 пиков, 0–10 банов, каталог из 126 героев, проверка уникальности |
| Публикации | Галерея, дублирование, удаление, неизменяемые версии (до 30), восстановление версии |
| Экспорт | PNG 1080 × 1080 и 1280 × 1280, проверка фактического размера |
| Хранение | Локальная SQLite-база на стороне сервера Nuxt |
| Резервная копия | JSON-файл со всеми данными и изображениями; восстановление объединением |
| Внешние данные | Импорт матчей из PandaScore и пиков/банов из OpenDota (по токенам в серверном окружении) |

## 3. Что не входит

- Авторизация, многопользовательская работа, облачные проекты и синхронизация.
- Live-публикации и автоматическое обновление уже сохранённых постеров.
- Свободное перемещение слоёв и пользовательские шаблоны.
- Прозрачный фон и форматы, отличные от квадратных.
- Пакетный экспорт.
- Мобильная версия и Safari не проверялись.

## 4. Ключевые инварианты

- Сохранённая публикация рендерится только из своего снимка.
- Команду, используемую в матчах, удалить нельзя.
- Экспорт PNG выполняется после сохранения публикации.
- Замена изображения создаёт новую запись, старые снимки сохраняют прежнюю.

## 5. Основной сквозной сценарий

1. Добавить две команды, при желании с логотипами, создать между ними серию BO3.
2. Создать публикацию «Анонс», настроить оформление, сохранить, скачать PNG и проверить размер.
3. После игры ввести счёт 2:1, создать публикацию «Итог серии»; данные подставляются автоматически, анонс остаётся прежним.
4. Для карты открыть генератор драфта, выбрать пики и баны, сохранить и экспортировать.

Негативные проверки: одинаковые команды, счёт 3:0 для BO3, дубль героя, повреждённое изображение, слишком длинные названия, WIN для проигравшей команды.
