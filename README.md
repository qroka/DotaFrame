# DotaFrame

**DotaFrame** — веб-приложение для создания графических публикаций о киберспортивных матчах Dota 2 на основе готовых шаблонов.

Проект ориентирован на SMM-специалистов киберспортивных команд, редакторов профильных СМИ и администраторов тематических сообществ. DotaFrame также развивается как учебный проект для практики HTML, CSS и JavaScript.

> **Статус:** ранний рабочий прототип. Реализован редактор анонса матча с предпросмотром и экспортом в PNG. Полноценный MVP с несколькими типами публикаций, сохранением матчей и библиотекой команд ещё в разработке.

## Зачем нужен DotaFrame

При освещении турниров приходится регулярно готовить анонсы матчей, драфты и результаты. Использование универсальных графических редакторов заставляет заново размещать одни и те же сведения о командах, турнирах и времени игр.

**Цель DotaFrame** — отделить данные матча от его оформления: заполнить информацию один раз и использовать её в нескольких готовых графических шаблонах. Сейчас реализована первая часть этой идеи — генератор анонса матча.

## Что уже работает

В текущем прототипе можно:

- изменять названия двух команд и турнира с немедленным обновлением постера;
- выбирать формат матча: **BO1, BO2, BO3 или BO5**;
- указывать время начала матча;
- просматривать постер в масштабе **50%** от исходного размера;
- скачивать карточку в формате **PNG 1080 × 1080 px**.

В редакторе используется один базовый шаблон — **Match Announcement**. Для слишком длинных названий предусмотрен перенос и ограничение количества строк.

## Быстрый старт

Для локального запуска нужны **Node.js** и **npm**.

1. Клонируйте репозиторий и перейдите в папку проекта:

   ~~~bash
   git clone https://github.com/qroka/DotaFrame.git
   cd DotaFrame
   ~~~

2. Установите зависимости:

   ~~~bash
   npm install
   ~~~

3. Запустите сервер разработки:

   ~~~bash
   npm run dev
   ~~~

4. Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173/`).

Для использования текущего прототипа не нужны серверная часть, учётная запись или API-ключи. Команда сборки для публикации пока не настроена.

## Как пользоваться

1. Введите названия команд и турнира.
2. Выберите формат серии и время начала.
3. Проверьте карточку в предпросмотре.
4. Нажмите **«Экспортировать в PNG»** — браузер скачает файл `dotaframe.png`.

Изменения в текущем прототипе не сохраняются между перезагрузками страницы.

## Технологии

| Инструмент | Для чего используется |
|---|---|
| HTML5 | Структура редактора и постера |
| Tailwind CSS v4 | Оформление интерфейса и шаблона |
| JavaScript (Vanilla JS) | Обработка ввода и обновление постера |
| Vite | Локальная разработка |
| html-to-image | Преобразование HTML-постера в PNG |
| Figma | Проектирование интерфейса и шаблонов |
| Git / GitHub | Контроль версий и управление задачами |

Исходный HTML-постер имеет размер 1080 × 1080 px. Масштабирование применяется к предпросмотру; при экспорте используются исходные размеры карточки.

## MVP: текущее состояние и планы

| Возможность | Состояние |
|---|---|
| Редактор анонса матча | **Реализован прототип** |
| Ввод команд, турнира, формата и времени | **Реализовано** |
| Предпросмотр изображения | **Реализован**, фиксированный масштаб 50% |
| Экспорт PNG 1080 × 1080 | **Реализован** |
| Дата матча и расширенные параметры оформления | Планируется |
| Справочник команд и загрузка логотипов | Планируется |
| Карточка результата серии | Планируется |
| Карточка драфта Dota 2 (герои, пики, баны) | Планируется |
| Создание и редактирование сохранённых матчей | Планируется |
| Локальное сохранение проектов и снимков публикаций | Планируется |
| Адаптивный интерфейс редактора | Требует доработки |

Для проектируемого MVP в документации приняты BO3 и BO5 как основные форматы серии; текущий прототип также позволяет выбрать BO1 и BO2. Подробные сценарии и требования представлены в [документации](docs/README.md).

## Ограничения прототипа

- Доступен только один упрощённый шаблон анонса без логотипов команд.
- Длинные названия могут обрезаться после двух строк; автоматического подбора размера шрифта пока нет.
- Предпросмотр имеет фиксированный масштаб; удобство на небольших экранах ещё предстоит улучшить.
- Данные не сохраняются: после обновления страницы изменения теряются.
- Экспорт PNG работает в базовом сценарии; дополнительные проверки шрифтов, изображений и разных браузеров запланированы.

## Дальнейшее развитие

Ближайшие этапы — доработка редактора анонса, добавление логотипов, поддержка карточек результатов и драфтов, сохранение матчей и расширение библиотеки шаблонов.

После MVP могут быть рассмотрены графика «Матчи сегодня» и «Матч начинается», интеграции с API, дополнительные размеры публикаций, фирменные стили и пакетная генерация. Эти функции **пока не реализованы**.
