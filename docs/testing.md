# Тестирование

Состояние на 12.11.2026:

- Юнит-тесты (Vitest): **130 из 130** проходят.
- Сквозные тесты (Playwright), Chromium: **15 из 15** проходят.
- Firefox: прогон не выполнялся, браузер не установлен в окружении разработки (`npx playwright install firefox`).

## Команды

```bash
npm test                         # юнит-тесты
npm run test:e2e                 # Playwright, Chromium
npm run test:e2e:cross-browser   # Chromium + Firefox
npm run test:all                 # юнит + e2e (Chromium)
```

Перед первым запуском e2e: `npx playwright install chromium firefox`.

Playwright сам поднимает два сервера (`tests/e2e/mock-pandascore.mjs` на порту 5200 и Nuxt dev через `tests/e2e/dev-server.mjs` на порту 5199 с отдельной базой `test-results/dotaframe-e2e.sqlite`, которая очищается перед прогоном). Лаунчер написан на Node, чтобы запуск не зависел от оболочки (работает в cmd, PowerShell и bash). Реальная база `.data/` в e2e не используется.

## Что покрыто

**Юнит-тесты** (`tests/unit`):
- правила счёта серий (BO1/BO2/BO3/BO5, ничья BO2), валидация матча и драфта, каталог героев и поиск по псевдонимам;
- история редактора: undo/redo, слияние быстрых правок, дешёвая проверка несохранённого (`editor-store.test.js`);
- репозиторий SQLite: команды, матчи, драфты, публикации, лимит 30 ревизий, настройки, внешние ссылки (`repository.test.ts`);
- бэкап: единая схема сверяется с живой схемой SQLite (`backup-schema.test.ts`); экспорт, восстановление, проверка версии и строк, откат при ошибке; лёгкий список публикаций; поиск и удаление неиспользуемых изображений (`backup-restore.test.ts`);
- безопасность медиа: определение типа по сигнатуре и заголовки ответа (`media.test.ts`);
- интеграции PandaScore и OpenDota, импорт, миграции (`pandascore*.test.ts`, `opendota.test.ts`);
- утилиты и сборка ссылок на изображения.

**Сквозные тесты** (`tests/e2e`):
- `data.spec.js` — навигация, создание команды и сохранение после перезагрузки, страница настроек;
- `editor.spec.js` — библиотека шаблонов, рендер общего конвейера, смена шаблона;
- `editor-history.spec.js` — Ctrl+S из поля названия, отмена и повтор, возврат к «Сохранено», отмена смены шаблона, подтверждение при уходе с несохранёнными изменениями, экспорт PNG 1080 × 1080 с автосохранением;
- `api.spec.js` — тип загрузки по байтам, заголовки `nosniff` и CSP, отказ при восстановлении (новая версия, не изображение), круговой цикл бэкапа, очистка изображений только с подтверждением, лёгкий bootstrap;
- `pandascore.spec.js` — импорт матча, готовность пакета, синхронизация и дедупликация.

## Не покрыто

- Размер PNG 1280, экспорт остальных шаблонов, драфт-генератор и счёт серий проверяются только юнит-тестами и вручную. Прежние сквозные сценарии (24 теста) были удалены при миграции на Nuxt и не восстановлены.
- Кроссбраузерность (Firefox) в текущем окружении не проверялась.
- Визуальные эталонные скриншоты не настроены.
- Адаптивность на узких экранах и ширины 1920+ проверялись только вручную.
- Восстановление большого бэкапа (сотни мегабайт): бэкап по-прежнему собирается целиком в памяти, нагрузочных тестов нет.
