
# DotaLab

DotaLab — персональное веб-приложение для анализа матчей Dota 2 и управления собственным пулом героев.

## О проекте

Проект разрабатывается в образовательных целях для изучения веб-программирования, проектирования информационных систем, UI/UX-дизайна и Git.

## Планируемые возможности

- Получение истории матчей через OpenDota API.
- Просмотр статистики матчей.
- Управление личным пулом героев.
- Добавление заметок к матчам.
- Анализ игровой статистики и построение графиков.

## Технологический стек

- HTML5
- Tailwind CSS
- JavaScript (Vanilla JS)
- OpenDota API
- Git и GitHub
- Figma

## Этапы разработки

1. Предпроектный анализ.
2. Проектирование информационной системы.
3. Разработка дизайн-системы и макетов.
4. Реализация приложения.
5. Тестирование и публикация.

## Статус проекта

Проект находится на этапе планирования и предпроектного анализа.
