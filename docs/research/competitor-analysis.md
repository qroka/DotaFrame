## 4. Анализ продуктов

### 4.1. Canva

**Основное назначение:** универсальный графический редактор.

**Подтверждённые возможности:** использование готовых шаблонов для спортивных и киберспортивных публикаций.

**Преимущества:** широкий выбор шаблонов и гибкость визуального оформления.

**Ограничения для сценария DotaFrame:** необходимо исследовать, насколько удобно многократно обновлять данные одной серии матчей.

### 4.2. ParaScores Graphics Studio

**Основное назначение:** генерация графики на основе данных турниров.

**Подтверждённые возможности:** создание результатов матчей, расписаний, турнирных таблиц и сеток с экспортом PNG.

**Преимущества:** повторное использование данных соревнования и автоматическая подготовка материалов.

**Ограничения для сценария DotaFrame:** необходимо исследовать применимость к матчам Dota 2 и публикациям драфтов.

### 4.3. FLM System

**Основное назначение:** управление спортивными лигами.

**Подтверждённые возможности:** генерация анонсов, результатов и расписаний с использованием сохранённых данных.

**Преимущества:** минимальное количество ручных действий при подготовке повторяющихся публикаций.

**Ограничения для сценария DotaFrame:** необходимо исследовать возможности адаптации к киберспортивным форматам.

### 4.4. LHM Ultra Dota 2 HUD

**Основное назначение:** графическое оформление трансляций Dota 2.

**Подтверждённые возможности:** оверлеи драфта, предматчевые и послематчевые экраны.

**Отличие от DotaFrame:** ориентация на графику трансляций, а не только на экспорт статичных социальных публикаций.
