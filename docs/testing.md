# Тестирование

Последний прогон юнит-тестов (12.11.2026): 75 из 75 проходят (Vitest). Сквозные тесты (Playwright) в этот день не перезапускались; прежний зафиксированный результат — 24 теста в Chromium и Firefox.

## Команды

```bash
npm test                # юнит-тесты
npm run test:e2e        # Playwright: Chromium + Firefox (dev-сервер поднимается сам, порт 5199)
npm run test:all
```

Перед первым запуском: `npx playwright install chromium firefox`.

## Что покрыто

**Юнит-тесты** (`tests/unit`): правила счёта серий (BO1/BO2/BO3/BO5, ничья BO2), валидация матча, валидация драфта, каталог героев и поиск по псевдонимам, undo/redo и признак несохранённых изменений, неизменность снимков публикаций, сборка ссылок на изображения (`collectAssetRefs`), утилиты и форматы дат.

**Сквозные тесты** (`tests/e2e`):
- экспорт всех шаблонов в 1080 и 1280 px с проверкой реальных размеров PNG;
- ошибка WIN для проигравшей команды блокирует экспорт;
- сохранённая публикация не меняется после переименования команды, смены логотипа и счёта;
- тема, фон-фото, undo/redo, отклонение битого файла;
- драфт: 10 пиков, защита от дублей, сохранение GameDraft, экспорт, восстановление после перезагрузки;
- команды: валидация, логотип, битый файл, сохранение после перезагрузки, замена логотипа создаёт новый файл;
- матчи: BO3 3:0 отклоняется, BO2 1:1 принимается, одинаковые команды отклоняются, форма создаёт матч;
- резервная копия: полный цикл с изображениями, отказ на чужих и более новых файлах;
- длинные кириллические названия не выходят за рамки макета.

## Не покрыто

- Визуальные эталонные скриншоты (сравнение пиксель в пиксель) не настроены; скриншоты шаблонов сохраняются в `test-results/` при прогоне и проверяются вручную.
- Адаптивность на узких экранах и ширины 1920+ проверялись только вручную и частично.
- Страницы публикаций, шаблонов и настроек проверены на открытие без ошибок, без отдельных сценариев.
- Рабочий процесс с реальными портретами героев (массовый импорт) проверен вручную в ходе разработки, автотеста нет.
